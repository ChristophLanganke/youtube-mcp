Langanke Media MCP

A personal Model Context Protocol server that gives an AI assistant read-only access to YouTube transcripts and to the operator’s own YouTube account data.

Registered with Google as the OAuth application Langanke Media MCP; distributed as the open-source project youtube-mcp.

What it does

The server runs locally on the operator’s own computer and is started by an MCP client such as Claude Desktop. It exposes a set of tools that let the assistant fetch a video’s subtitle track as plain text — so a long video can be summarised, translated or quoted without watching it — and, after the operator signs in with Google, read their own subscriptions, playlists and uploads.

Scope of access

The application requests two Google OAuth scopes:

  • youtube.readonly — read the signed-in account’s subscriptions, playlists and uploads.
  • youtube.force-ssl — required by the YouTube Data API for captions.download, which can only retrieve caption tracks of videos the signed-in account owns.

The application is read-only. No tool uploads, edits, deletes or publishes anything on the connected YouTube account, and none is capable of doing so.

Who runs it

This is a single-operator personal project, not a hosted service. There is no server, no user account system and no shared infrastructure — every installation runs entirely on the computer of the person who installed it, and their data never leaves that machine except in the requests they themselves initiate.
